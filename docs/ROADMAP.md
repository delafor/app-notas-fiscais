# Roadmap para produção

## Fase 1 — Fundação
- [ ] Arquitetura por feature.
- [ ] Lint e análise estática.
- [ ] Tratamento global de erros.
- [ ] Revisão de dependências.

## Fase 2 — Qualidade
- [ ] Testes das regras fiscais críticas.
- [ ] Testes de autenticação.
- [ ] Estados de loading/empty/error.
- [ ] Testes de integração dos fluxos críticos.

## Fase 3 — Segurança e operação
- [ ] Revisão das Firebase Rules.
- [ ] Auditoria de secrets/configuração de release.
- [ ] Crash reporting e logging.
- [ ] CI com analyze, test e build.

## Fase 4 — Release Candidate
- [ ] Testes em dispositivos suportados.
- [ ] Performance e acessibilidade.
- [ ] Versionamento e changelog.
- [ ] Checklist de publicação aprovado.

## Fase 5 — Produção
- [ ] Publicar somente com bloqueadores críticos fechados.
- [ ] Monitorar erros e crashes.
- [ ] Manter plano de rollback.
