# Release checklist

## Antes
- [ ] `flutter analyze` verde.
- [ ] `flutter test` verde.
- [ ] Build de release validado.
- [ ] Versão/build number atualizados.
- [ ] Firebase Rules revisadas.
- [ ] Configurações de produção conferidas.
- [ ] Fluxos críticos testados manualmente.
- [ ] Crash reporting ativo.

## Depois
- [ ] Monitorar crashes e erros.
- [ ] Validar login e fluxos fiscais.
- [ ] Registrar versão publicada.
- [ ] Manter plano de rollback.
